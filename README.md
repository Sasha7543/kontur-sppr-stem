## 1. Призначення та ролі

**«Контур-СППР»** — клієнтська частина (SPA) геоінформаційної системи підтримки прийняття рішень (СППР) для оцінки ризиків та пріоритизації гуманітарного розмінування територій.

Система підтримує **дві ролі**:
* **Аналітик-сапер ІРГ (інженерно-саперної групи):** моніторить поточний стан верифікації сектора (віджет на 7 станів), працює з інтерактивною ГІС-картою полігонів замінування (Leaflet + Esri ArcGIS Topo / Satellite), калібрує вагові коефіцієнти 5 критеріїв СППР за методом зваженої лінійної згортки (WLC / Сааті), контролює прогноз очищення площі до кінця місяця з 90% довірчим інтервалом ($z = 1,645$), переглядає 7-денний розклад виїздів комплексів Armtrac-400 та експортує звіти в PDF і CSV (Excel).
* **Диспетчер штабу ДСНС:** координує регіональні ресурси, використовує інтерактивний «Симулятор життєвого циклу сектора» для перевірки всіх 7 станів віджета верифікації, генерує токени допуску для нових саперних екіпажів та розсилає оперативні директиви безпеки з автоматичною санітизацією XSS-ін’єкцій (DOMPurify).

## 3. Архітектурна організація клієнтської частини

* `core/` — конфігурація маршрутизатора, провайдери денної та нічної тактичної теми, захисники маршрутів за роллю (`RoleGuard`) та каркас сторінки з темною бічною навігацією (від 1024 px) і мобільним нижнім доком (до 1024 px);
* `modules/` — функціональні домени системи (інтерактивна карта Leaflet, матриця багатокритеріальної оптимізації СППР, модуль інтервального прогнозування темпів розмінування, журнал виїздів, генератор PDF/CSV-актів, консоль диспетчера штабу);
* `shared/` — типізовані контракти даних TypeScript, математичні функції обчислення індексу ризику $R_i$ та 90% довірчого коридору, утиліти санітизації XSS та захисту від CSV-ін’єкцій;
* `server-mock/` — імітатор геоінформаційного REST API зі збереженням стану в `localStorage`.

## 4. Математична модель СППР та інтервальне прогнозування

1. **Багатокритеріальне ранжування небезпечних ділянок (метод WLC / Сааті):**
   $$R_i = 100 \cdot \sum_{j=1}^{5} \frac{w_j}{\sum w} \cdot \left(\frac{k_{ij}}{10}\right)$$
2. **Адаптивний прогноз площі очищення до кінця місяця ($\beta = 0,72$):**
   $$S_{\text{prog}} = S_{\text{fact}} + d_{\text{rem}} \cdot \left(\beta \cdot v_{\text{mech}} + (1 - \beta) \cdot v_{\text{sap}}\right)$$
   Межі 90-відсоткового довірчого інтервалу прогнозу ($z_{0,90} = 1,645$):
   $$S_{\min, \max} = S_{\text{prog}} \pm z_{0,90} \cdot \sigma_s \cdot \sqrt{d_{\text{rem}}}$$
